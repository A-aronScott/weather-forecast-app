
# Weather Forecast App – Workspace Rules

## Learning and Communication
- Treat this as a learning project.
- Explain unfamiliar concepts using clear, beginner-friendly language.
- Work on one meaningful step at a time.
- Keep explanations and responses concise.
- Help me understand the code rather than simply generating it.

## Development Workflow
- Use Plan mode before significant development tasks.
- Inspect relevant files before proposing changes.
- Present a short plan and wait for approval before implementing it.
- Ask permission before editing files, running commands, installing packages or performing Git operations.
- Avoid unnecessary changes and rewriting working code.

## Code Quality
- Prefer simple, readable JavaScript and React code.
- Use meaningful variable and function names.
- Explain important implementation decisions.
- Do not introduce additional libraries without discussing them first.

## Token Efficiency
- Avoid unnecessary file reads and repeated analysis.
- Do not repeat information already established.
- Do not use subagents unless approved.
- Keep prompts and responses focused.

## Git and GitHub
- Review changes before committing.
- Use descriptive commit messages.
- Remind me to commit after each meaningful, tested milestone.
- Ask before committing or pushing.

## Security
- Never expose or commit API keys, passwords or other secrets.
- Check that `.gitignore` excludes environment files before adding API keys.
